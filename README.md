# Redmine 專案管理系統使用教學

本教學以 Redmine 5.x / 6.x 繁體中文介面為準，依照使用者身分分成四個章節，從一般成員的日常操作，到專案經理的專案規劃，再到系統管理員的後台設定，循序說明。

> 不同版本或安裝了外掛的 Redmine，選單名稱與位置可能略有差異，請以實際畫面為準。

## 目錄

| 章節 | 適合對象 | 內容 |
|---|---|---|
| [01 入門與介面導覽](docs/01-getting-started.md) | 所有人 | 登入、畫面配置、個人帳戶設定、我的頁面 |
| [02 一般成員操作](docs/02-member.md) | 一般成員 | 瀏覽專案、建立與更新議題、觀察、記錄工時、篩選與搜尋 |
| [03 專案經理操作](docs/03-project-manager.md) | 專案經理 | 建立專案、成員與版本、分派工作、甘特圖、路線圖、Wiki |
| [04 系統管理員操作](docs/04-administrator.md) | 系統管理員 | 使用者與群組、角色權限、追蹤標籤、議題狀態、工作流程、自訂欄位 |
| [05 常見問題](docs/05-faq.md) | 所有人 | 常見狀況與排解方式 |

## 核心名詞速查

| 名詞 | 說明 |
|---|---|
| 專案 | 工作的最上層容器，可設定子專案 |
| 議題 | 一筆待辦工作，可以是錯誤、功能或支援請求 |
| 追蹤標籤 | 議題的類型，例如「錯誤」、「功能」、「支援」 |
| 狀態 | 議題目前所在的階段，例如「新建立」、「進行中」、「已解決」、「已結案」 |
| 版本 | 專案的里程碑或發佈版本，議題可指定目標版本 |
| 角色 | 成員在專案中的身分，決定能做哪些操作 |
| 工作流程 | 定義各角色能把議題從哪個狀態改成哪個狀態 |
