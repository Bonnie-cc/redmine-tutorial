# Redmine 使用教學（繁體中文）

一份給所有 Redmine 使用者的繁體中文教學。從「Redmine 是什麼」開始，涵蓋一般成員的日常操作、專案經理的規劃與追蹤、系統管理員的後台設定，一直到自行架站的安裝、備份與升級。

- **適用版本**：以 Redmine 5.x～7.x 為準（撰寫時最新版本為 7.0）。只在較新版本才有的功能，會在標題或內文標註，例如「（5.0+）」。
- **介面語言**：以繁體中文介面為主。用「」標示的按鈕、選單與欄位名稱，一律照 Redmine 官方繁體中文翻譯，和你的畫面一致；內文說明則使用較口語的說法（例如畫面上的「監看」，內文會說「觀察」或「追蹤」）。重要名詞附上英文原文，方便英文介面的使用者對照，也方便查詢官方文件。兩者的對照請見 [附錄 A](docs/appendix-a-glossary.md)。
- **差異提醒**：Redmine 可以安裝外掛、更換佈景主題，各站台的設定也不同，你看到的選單名稱與位置可能和教學略有差異，請以實際畫面為準。本教學中屬於外掛的功能，都會標註「需安裝外掛」。

## 核心名詞速查

| 名詞 | 英文 | 說明 |
|---|---|---|
| 專案 | Project | 工作的最上層容器，可設定子專案 |
| 議題 | Issue | 一筆待辦工作，可以是錯誤、功能或支援請求 |
| 追蹤標籤 | Tracker | 議題的類型，預設有「臭蟲」（錯誤）、「功能」、「支援」 |
| 狀態 | Status | 議題目前所在的階段，例如「新建立」、「實作中」、「已解決」、「已結束」 |
| 版本 | Version | 專案的里程碑或發佈版本，議題可指定目標版本 |
| 角色 | Role | 成員在專案中的身分，決定能做哪些操作 |
| 工作流程 | Workflow | 定義各角色能把議題從哪個狀態改成哪個狀態（畫面上稱為「流程」） |

更完整的對照表請見 [附錄 A](docs/appendix-a-glossary.md)。

## 關於教學中的圖片

教學中的步驟圖為示意圖，畫面中的專案、人名、網址與電子郵件皆為虛構資料。示意圖的細節不一定與你的 Redmine 完全相同，操作時請以實際畫面為準。
