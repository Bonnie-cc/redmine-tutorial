# 附錄 B 速查表

[← 回目錄](../README.md)

最常用的操作與語法整理在這一頁，可以印出來放在手邊。

## 日常操作

| 我想要… | 怎麼做 |
|---|---|
| 看我手上的工作 | 「帳戶首頁」→「分派給我的議題」 |
| 新增議題 | 專案「議題清單」頁籤 →「建立新議題」 |
| 回報進度 | 打開議題 →「編輯」→ 改狀態、寫筆記 →「送出」 |
| 記錄工時 | 打開議題 →「記錄時間」 |
| 追蹤某筆議題的變化 | 打開議題 →「監看」 |
| 通知特定同事 | 在筆記中輸入 `@帳號`（5.0+） |
| 快速跳到某筆議題 | 搜尋框輸入 `#123` |
| 批次修改議題 | 議題清單勾選多筆 → 按右鍵 |
| 存下常用篩選 | 設定篩選 →「套用」→「儲存」 |
| 匯出清單 | 議題清單右下角「匯出至」→ CSV / PDF |

## 連結語法

| 語法 | 連結到 |
|---|---|
| `#123` | 議題 |
| `##123` | 議題（顯示追蹤標籤與主旨） |
| `#123-4` | 議題的第 4 則筆記 |
| `[[頁面名稱]]` | Wiki 頁面 |
| `version:"v1.0"` | 版本 |
| `attachment:檔名` | 附件 |
| `@帳號` | 提及使用者（5.0+） |
| `commit:a1b2c3d` | Git 提交 |
| `!#123` | 不要轉成連結 |

## 文字格式

| 效果 | CommonMark Markdown | Textile |
|---|---|---|
| 粗體 | `**文字**` | `*文字*` |
| 標題 | `## 標題` | `h2. 標題` |
| 清單 | `- 項目` | `* 項目` |
| 連結 | `[文字](網址)` | `"文字":網址` |
| 圖片 | `![](檔名.png)` | `!檔名.png!` |
| 程式碼區塊 | ```` ``` ```` 包住 | `<pre>` 包住 |
| 目錄 | `{{toc}}` | `{{toc}}` |

## 提交訊息關鍵字（需管理員設定）

| 寫法 | 效果 |
|---|---|
| `refs #123` | 提交關聯到議題 |
| `fixes #123` | 關聯並自動改狀態（依站台設定） |
| `refs #123 @2h` | 關聯並記錄 2 小時工時（需啟用） |

## 常用篩選

| 想看的內容 | 篩選條件 |
|---|---|
| 我未完成的工作 | 狀態：進行中、被分派者：<<我自己>> |
| 已逾期 | 狀態：進行中、完成日期：大於幾天之前 1 天 |
| 待分派 | 狀態：進行中、被分派者：空值 |
| 本週到期 | 狀態：進行中、完成日期：本週 |

> 篩選條件中的「狀態：進行中」代表所有尚未結束的議題。
