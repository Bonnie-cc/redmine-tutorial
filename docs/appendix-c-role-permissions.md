# 附錄 C 角色權限建議

[← 回目錄](../README.md)

以下是常見角色的權限設定參考，可以作為設定「網站管理」→「角色與權限」的起點，再依團隊需求調整。設定方式見 [7.4 角色與權限](07-administrator.md#74-角色與權限)。

## 建議的角色

| 角色 | 適合誰 | 一句話說明 |
|---|---|---|
| 管理人員 | 專案經理 | 可以管理專案設定、成員與版本 |
| 開發人員 | 實際執行工作的人 | 可以處理議題、記錄工時、編輯 Wiki |
| 報告人員 | 需求方、測試人員、客戶 | 可以回報議題、留言、驗收 |
| 檢視者 | 主管、相關部門 | 只能看，不能改 |

> 「管理人員」、「開發人員」、「報告人員」是載入預設組態後的角色名稱；「檢視者」不是 Redmine 預設的角色，需要自行新增。

**議題可見度建議**

| 角色 | 建議設定 |
|---|---|
| 管理人員 | 所有議題 |
| 開發人員 | 所有議題 |
| 報告人員 | 所有非私人議題；若報告人員是外部客戶，可設為「使用者所建立的或被分派的議題」 |
| 檢視者 | 所有非私人議題 |

## 兩個特殊角色

| 角色 | 代表誰 | 公司內部建議 | 開源或對外專案建議 |
|---|---|---|---|
| 非會員 | 已登入，但不是此專案成員的人 | 取消所有權限 | 檢視議題、新增議題 |
| 匿名者 | 未登入的訪客 | 取消所有權限 | 只開放檢視 |

> 這兩個角色的權限只對「公開」的專案生效。不公開的專案，非成員與匿名使用者本來就看不到。
