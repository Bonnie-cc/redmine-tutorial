# 05 常見問題

[← 回目錄](../README.md)

### Q1：我看不到某個專案？

你可能不是該專案的成員，或專案沒有設為公開。請聯絡專案經理把你加入成員。

### Q2：議題的「狀態」下拉選單裡沒有我要的選項？

狀態的可選項目由「工作流程」控制。你的角色在這個追蹤標籤上可能沒有被允許做這個轉換，請洽系統管理員檢查工作流程設定。

### Q3：甘特圖上看不到我的議題？

甘特圖只顯示同時填寫「開始日期」與「完成日期」的議題（或有指派目標版本且版本有日期的議題）。請補上日期後再查看。

### Q4：收不到電子郵件通知？

請依序檢查：

1. 「我的帳戶」中的電子郵件地址是否正確。
2. 「電子郵件通知」選項是否設為「無」或範圍太窄。
3. 是否勾選了「不要將我自己所做的變更通知我」（自己改的東西本來就不會通知自己）。
4. 信件是否被分類到垃圾郵件。
5. 以上都正常的話，請管理員到「管理」→「設定」→「電子郵件通知」寄送測試郵件確認 SMTP 設定。

### Q5：議題送出後發現寫錯了，可以刪除嗎？

一般成員通常沒有刪除議題的權限。可以直接「編輯」修正內容，或將狀態改為「已拒絕」並在筆記說明原因。若真的需要刪除，請聯絡專案經理或管理員。

### Q6：通知信裡的連結打不開或網址錯誤？

這是「主機名稱與協定」設定錯誤造成的，請管理員到「管理」→「設定」→「一般」修正。

### Q7：如何在議題或 Wiki 裡連結其他內容？

| 語法 | 效果 |
|---|---|
| `#123` | 連結到議題 #123 |
| `[[頁面名稱]]` | 連結到同專案 Wiki 頁面 |
| `version:v1.0` | 連結到版本 v1.0 |
| `document:"規格書"` | 連結到文件 |
| `r100` | 連結到版本庫修訂版 100 |
| `@帳號` | 提及使用者並通知對方（Redmine 5.0 以上） |

### Q8：如何一次匯入大量議題？

Redmine 4.1 以上支援從 CSV 匯入議題。進入「議題」頁籤，點右上角「…」選單中的「匯入」，上傳 CSV 檔並對應欄位即可。
